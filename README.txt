# FF RECOVERY BOT

ملفات بداية لبوت تيليغرام يستقبل طلبات المساعدة ويرسلها إلى المشرف.

## مهم قبل التشغيل
- لا تطلب من المستخدمين كلمات المرور أو رموز التحقق أو مفاتيح API.
- لا تدّعِ أنك تستطيع استرجاع الحساب بنفسك؛ وجّه المستخدم إلى دعم اللعبة الرسمي.
- لا تضف نظام دفع أو تجمع أموالاً قبل الحصول على موافقة ولي أمرك وفهم شروط المنصة والقوانين المحلية.

## الملفات
- `bot.py`: كود البوت.
- `requirements.txt`: المكتبة المطلوبة.

## الإعداد
1. احتفظ برمز BotFather سرياً ولا ترسله لأي شخص.
2. ثبّت Python 3.10 أو أحدث.
3. افتح الطرفية داخل مجلد المشروع ونفّذ:
   `python -m pip install -r requirements.txt`
4. عيّن متغير البيئة `BOT_TOKEN` إلى رمز البوت.
5. عيّن `ADMIN_ID` إلى رقم حساب تيليغرام الخاص بالمشرف (اختياري).
6. شغّل:
   `python bot.py`

لا تضع رمز البوت داخل رسائل عامة أو صور أو ملفات منشورة.
